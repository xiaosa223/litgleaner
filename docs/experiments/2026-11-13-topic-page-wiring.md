# 课题页接线实测（2026-11-13）

课题页的调研进度、阅读路线、课题地图原先是示例数据。这次接到已有的后端接口，并按新手路径在浏览器里走了一遍。

## 环境

- 独立实例：仓库演示配置复制到会话临时目录，数据库、blob、备份、推送输出都改到临时目录。
- 来源：启用真实 OpenAlex（免费、只读，无联系邮箱），其余为演示适配器；调研上限调小（每轮候选 20，每类历史检索 8，扩展 5，种子 3）。
- 课题：演示课题，检索词临时改为 “EEG foundation model”；模型为假适配器，不产生费用。

## 走查结果

| 场景 | 结果 |
|---|---|
| 未调研 | 说明调研做什么，强调开始前会先给出篇数和费用 |
| 没有支持调研的来源（演示默认配置） | 预览返回 0 篇候选；弹窗说明不会调用模型、不产生费用，原因是没有启用 OpenAlex 或 Semantic Scholar，缺口说明换成中文 |
| 开始调研 | 约 4 秒拿到 OpenAlex 的 20 篇候选；弹窗列出已在文库的篇数、各步模型调用次数、预计费用及“估算不是上限”、轮数 |
| 执行 | 确认后显示“调研进行中”，约 10 秒完成两轮，自动刷新统计和每轮表格 |
| 阅读路线 | 真实论文按综述、代表作分组，标题可点进阅读页，显示年份和阅读价值（/100） |
| 课题地图 | 预览说明发送篇数和费用；确认后轮询，约 4 秒出现 5 个分组，论文标题从阅读路线补全 |
| 没有配置初筛模型 | 确认调研返回 409，原地弹出“先配置一个模型”，写明“每日初筛”需要模型 |

## 发现并修复的问题

1. 原“再扩展一轮”按钮调用确认接口时不带 `plan_id`，会被后端拒绝；改为先预览再确认。
2. 0 候选时弹窗仍列出“约 0 次调用”和病句“从 已启用的 个来源”；改为说明原因和下一步。
3. 后端缺口说明含内部代号（`highly_cited` 等）；前端换成中文。
4. 最后一轮 0 候选时提示“等初筛完成后再看”，实际没有要初筛的论文；改为“最近一轮没有找到新的候选论文”。
5. 来源回执两行都显示 “openalex 0 篇”；加上检索方式。
6. 第一轮全部复用时写“约 0 次调用”却又给出费用；改为说明复用，费用注明含后面几轮的上限估算。
7. “论文 0” 与 “新加入 13 篇” 看似矛盾：该标签只列每日推荐，改名“每日推荐”并在空状态说明调研论文在哪里看。
