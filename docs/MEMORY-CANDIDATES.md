# 文库候选排序

候选排序合并文库事实、当前本地向量和已有文本索引，为后续关系核实提供名单。分数用于排序，语义关系由 [ADR 0010](adr/0010-paper-memory.md) 的 `relate` 任务附双方原文核实。

## 只读接口

```http
GET /api/papers/{paper_id}/memory-candidates
GET /api/papers/{paper_id}/memory-candidates?limit=3
```

本篇和候选都限完整文库，包括阅读状态、有效笔记或已添加论文；未进入文库及未知论文返回 404。接口沿用本地会话、Host 和 Origin 保护。`limit` 可为 1–200，只能进一步缩小配置的候选数量；默认返回配置的 `max_pairs`。

响应包含本篇、`policy_hash`、实际 `query_terms`、候选 `matches`、截断前合格候选总数 `total`、实际 `limit`、嵌入器状态和诊断。候选按总分降序、论文 ID 升序排列，每条保留：

- `facts`：双方直接引用、共同参考目标、共享概念及已核验方法和数据集，沿用[事实查询的证据规则](PAPER-MEMORY.md)。
- `signals`：原始计数、双向直接引用是否存在、优先引用意图是否命中、原始余弦及归一化文本分数；缺少连续信号时为 `null`。
- `score`：总分与各项实际值、权重、贡献，便于核对排序。
- `vector`：实际选用的生产者和双方输入指纹。
- `text_hits`：各类最强文本命中的原始 BM25、来源类型、ID、页码和版本。

一次请求固定 10 次 SELECT，所有原始行取自同一短事务，事务外做领域转换和评分。查询不补索引、不读归档、不加载 SDK、不生成向量、不排队，也不调用模型。已有事实、向量和过期报告分别保留 8、4、15 次查询合同。

## 策略配置

`config/memory.yaml` 可同时配置本地向量和候选策略；文件缺失时沿用默认值：

```yaml
candidates:
  max_pairs: 5
  common_reference_min: 2
  cosine_min: 0.5
  minimum_score: 0.5
  query_terms_limit: 32
  weights:
    direct_citation: 6
    citation_intent: 5
    common_references: 4
    core_concepts: 4
    methods: 4
    cosine: 3
    datasets: 2
    text: 1
```

这些是待真实案例校准的初始值。`policy_hash` 包含全部策略参数、评分及词法协议；修改权重或阈值后立即只读重排，已有向量和事实保持各自的指纹。

| 分项 | 实际计分值 |
|---|---|
| 直接引用 | 任一方向有精确直接引用时为 1 |
| 引用意图 | 直接引用同时有非空上下文和 `method/methods/methodology/extends/extension` 意图时为 1；统一 Unicode 和大小写 |
| 共同参考文献 | 唯一目标数达到 `common_reference_min` 时为 1 |
| 核心概念、方法、数据集 | 对应字段至少一个有效匹配时，各为 1 |
| 余弦 | 当前有效双方向量的原始余弦达到 `cosine_min` 时取非负值，否则为 0 |
| 文本 | 每篇最强有效 BM25 的相反数，除以本次所有有效候选中的最大值 |

每项乘权重后求和，仅返回正分且达到 `minimum_score` 的候选。引用双向、多来源、多位置、多个共享概念或多个匹配块都不会重复抬高同一分项。权重可以设为零，零总分不进入名单。候选总数在数量截断前计算，超过文库默认分页范围的论文也参与排序。

## 来源与失效护栏

事实字段复用最新提取的输入、生产者及原文核验规则，不回退旧提取。未配置提取模型时，输入仍可核对的提取可以参与，并附生产者未完整核验的诊断。缺提取、提取失效或向量未就绪时，其他信号独立可用。

余弦只使用同当前生产者、配置、维度和实际文本的有效 float32 向量，见[本地向量](LOCAL-EMBEDDINGS.md)。只由向量或文本命中的论文也能进入候选，不要求先有事实关系。

FTS 词来自本篇标题与摘要的前 8192 字符：先统一 Unicode、大小写和空白，再按出现顺序取不同词，默认最多 32 个，可配置为 1–64。普通词保留三字以上的整词，连续中日韩文字取三字窗口；混排按文字连续段拆分。常见英文虚词、不足三字及超过 64 字符的普通词跳过。词按字面 OR 召回，用户内容不能变成 FTS 操作符。

命中只取已有 `paper/fulltext/extraction` 索引；个人笔记、高亮、问答和概念条目不作论文正文信号。论文元数据索引需对应其论文 ID，全文需对应当前文档指针，提取需对应最大提取 ID 且通过输入和生产者护栏。先排失效来源，再选每篇每种来源最强命中，最后归一化；索引缺失时文本信号缺席。

词归一只作用于查询，既有 trigram 索引保留原文字形。因此全角 Latin、`ß` 等字形可漏召回，索引规范化需后续统一处理。普通英文及中日韩词法已有离线回归。

当前验收使用真实临时数据库、离线嵌入器、真实 API 和安全入口。真实论文的召回效果与权重调参待实测；首次入库自动处理、重要前作、未链接提及、`relate`、全局检索及问答的混合召回继续按 ADR 分段接线。
