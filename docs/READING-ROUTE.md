# 阅读路线与研究目标关联

`GET /api/topics/{topic_id}/reading-route?limit_per_group=10` 返回课题当前画像下通过初筛的论文。需要本地会话，每组上限为 1–100；该接口只读取数据库，不请求来源或模型，模型未配置、预算不足和课题暂停时均可查看。

路线由 `domain.reading_route.order_route` 排列，按下面的顺序选取，每篇最多出现一次：

| 分组 | 选择和排序依据 |
|---|---|
| `reviews` | 来源明确标注的综述类型，按出版日期降序；不根据标题猜类型 |
| `foundations` | 当前课题内通过初筛的论文对它的引用数，降序排列；同数时较早出版者优先 |
| `representatives` | 当前有效阅读价值分，降序排列；0 分仍是有分数，未知分数不填 0 |
| `recent` | 近两个日历年内的剩余论文，按出版日期降序；忽略未知或未来日期 |

未分组和超过分组上限的剩余论文保留在 `ungrouped`，`total` 为本次候选总数。各分组依次选取，前组已选论文不会重复进入后组。

引用数只统计当前画像下通过初筛的不同引用论文；同一篇论文的多个来源条目只计一次，自引不计。未直接关联的引文沿用引文库按唯一标识符匹配的规则。来源提供的总被引数不冒充课题内引用数。

代表作只使用当前课题指纹、当前评价语义和算分规则，以及当前正文/摘要、阅读语言、切分、输入格式版本和正文 token 预算匹配的评分。输入变化后保留论文事实，分数与目标关联返回未知或空值，不触发重评。旧结果缺少目标关联时也不自动补生成。论文、评分、全文状态和课题内引用数通过固定 4 次批量查询读取；每组上限只限制路线展示，不影响候选和遗漏计数。

每篇返回文献编号、标题、出版日期、来源类型、课题内引用数、可用的分数/临时分标志和 `goal_links`。目标关联在同一次 `assess` 模型调用中生成，不另加调用：

```json
{
  "goal_id": "g1",
  "reuse": "可以借鉴什么，以及与该研究目标的关系",
  "quote": "论文连续原文，或 null",
  "page": 0,
  "verified": true
}
```

不存在的目标编号会丢弃。正文输入保留实际块的 `[page=零基页码 ...]` 标记，跨页段落的后续页也有独立标记。正文引用要求原页与实际清洗后发送的同一页内容同时匹配；摘要评估只能在 `page=null` 时按实际摘要核验。缺失、过短、未发送或页码不符的引文保留但标记 `verified=false`，不得显示为已核实作者原话。页码为 PDF 零基页码。

`goal_links` 独立保存到 `assessment`，不参与阅读价值算分。原结果只追加、不覆盖，修改模型或提示词后不静默重评。初筛、提取、评估的实际费用记录到对应论文。
