# 模型原地配置

本地服务提供模型配置接口，领读器在两处调用：设置页的“模型”一节，以及第一次用到模型时的原地弹窗（翻译、整篇翻译、边读边问收到 `model_configuration_required` 时弹出，保存后自动继续刚才的操作；问答的问题已排队，配好后自动回答）。表单提供 DeepSeek、智谱、OpenAI、Anthropic、Gemini 和“其他 / 本地网关”六个预设：预设只填协议、地址、结构化方式和输出上限字段名，价格不写死，由用户按官网价格页填写（免费模型填 0）。默认所有任务用同一个模型，高级选项里可以只选部分任务。“测试并保存”先实际调用一次，测试失败时可以选择“仍然保存”。现有命令行 YAML 配置继续可用；缺少 `llm.yaml` 时按未配置启动，阅读 PDF、批注和本地检索照常可用。

所有接口沿用启动会话、Host/Origin 和 CSRF 检查。响应不返回密钥全文，校验错误不回显请求体。

| 接口 | 行为 |
|---|---|
| `GET /api/settings/models` | 返回提供方、任务、预算和可用协议；任务配置状态与演示适配器分开；密钥只显示已设置与末四位 |
| `POST /api/settings/models/test` | 草稿参数发送固定短内容；后台任务验证结构化输出，翻译验证流式输出，按所选任务测试对应能力；返回结果和费用，不写配置或钥匙串 |
| `PUT /api/settings/models` | 校验后保存配置和密钥，后续请求及下一轮调度使用新配置；不调用模型 |

测试与保存接收相同参数：

状态中的 `ready` 表示任务路由已构建；连接测试单独返回本次实际协议响应的能力结果。

```json
{
  "provider": "personal",
  "protocol": "openai_chat",
  "model": "YOUR_MODEL",
  "tasks": ["translate"],
  "base_url": "http://127.0.0.1:3425/v1",
  "api_key": "YOUR_KEY",
  "input_price": 0,
  "output_price": 0,
  "daily_budget_usd": 2,
  "task_budgets_usd": {"translate": 0.5},
  "max_output_tokens": 4000,
  "structured": "native",
  "max_tokens_field": "max_tokens"
}
```

价格单位是美元/百万 token，须填提供方实际价格。`max_tokens_field` 可选，只接受 `max_tokens` 或 `max_completion_tokens`：OpenAI 兼容接口（国内厂商、中转站、本地网关）常常只认 `max_tokens`，省略时沿用已有配置或协议默认字段。协议由状态接口返回，目前支持四种 API 协议。`tasks` 只允许已实现的 `triage`、`extract`、`assess`、`translate`、`ask`、`map`、`outline`、`relate`，只启用明确选中的任务。同一提供方若还被其他未选任务使用，须选择新名称，或把需要同步修改的任务都选上。同协议编辑保留 YAML 中的兼容参数和自定义提示词；业务参数的有效值未变时保留原配置表示，避免仅改限额使旧缓存过期。没有 key 的本地网关可省略 `api_key`；省略已有提供方的 key 表示沿用密钥引用。

连接测试会实际调用模型并计费，每次调用前检查当日预算，已知费用写入 `llm_call`。失败响应提供了用量时也记账；提供方未返回用量时无法确认实际费用。测试的输出上限是 1024 token（用户设置更小时取用户值）：推理模型先思考再作答，上限太小会把可用模型误报为连接失败（实测免费推理模型回答一句话约用 250 token）。返回的 `estimated_usd` 是按这个上限算的费用上限（最多两次调用）。测试使用当前已保存的预算；保存新的预算后才影响后续调用。

业务任务可分别设置每日限额，状态接口在每个任务下返回 `daily_budget_usd`。保存时用 `task_budgets_usd` 按名称修改已选任务：缺少的键保留原限额，显式 `null` 清除单独限额，`0` 暂停该任务的新调用；未选择任务的限额不能修改。只接受非负有限数，拒绝布尔、数字字符串和非有限数。界面目前只设置全局每日上限；单个任务的限额可通过接口或 YAML 设置：

```yaml
tasks:
  translate:
    provider: personal
    model: YOUR_MODEL
    prompt: translate
    daily_budget_usd: 0.5
budget:
  daily_usd: 2.0
```

全局与任务限额同时生效，按 UTC 自然日归属费用；历史费用记录的时区偏移也会换算。每个任务的成功响应及有已知用量的失败响应都累计到该任务；更换模型或提供方不会重置当天用量。连接测试记为 `configuration_test`，只受已保存的全局预算限制。预算在调用开始前检查，单次调用可能超过剩余额度；并发调用没有费用预留。

任务额度用完后，队列将任务推迟到下一个 UTC 日界，不增加失败次数，也不因等待预算而进入死信；其他任务继续执行。预算和本地前置等待会打断外部连续等待的计时，恢复后首次遇到外部限频或处理中状态时才重新起算，真正连续的外部等待仍会超期。全局预算耗尽或缺模型停止阶段时，也会重置本轮剩余且属于当前执行范围的任务计时，其他阶段、未选择和被调研占用的任务保持原状。已经推迟的任务在到期时重查额度，调整限额不会立即提前其排定时间。全局预算耗尽保持本轮停止、任务待处理的行为。修改限额不改变生产者指纹，已有有效缓存继续可用，不自动重算历史。

密钥写入系统钥匙串：macOS Keychain、Windows WinVault、Linux SecretService。没有可用钥匙串时，环境变量仍可读取，写入明确失败；不会回退到明文文件。环境变量优先于钥匙串。YAML 只存密钥名，原配置精确备份到 `llm.yaml.bak` 后原子替换；写入失败保留旧配置和旧运行时，清理本次新建密钥。检测到用户从磁盘修改配置时拒绝覆盖。

正在执行的请求和 SSE 固定使用开始时的运行时快照。保存后新请求取新快照，原请求继续完成；历史提取、评估和译文不会因保存而自动重算。

缺少模型时，HTTP 返回 `409` 和 `code=model_configuration_required`、`task`；预算用完返回 `402` 和 `code=budget_exceeded`，任务限额错误另带 `task`。SSE 错误同样包含稳定 `code`、原有 `message` 和适用时的 `task`；问答状态接口会把任务限额不足显示为 `budget_exceeded`。后台任务保持 pending，缺模型不计重试次数；配置完成后可继续执行。

`relate` 新设置默认每日额外限额 0.2 美元，可修改或显式清除；首次入库、回填及双方原文规则见 [论文关系核实](PAPER-RELATIONS.md)。
