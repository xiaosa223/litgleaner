# 用户需求

由三轮公开内容调研整理而成：小红书（11 篇帖子）、第二轮假设检验（25 条证据）、X 与论坛（21 个线程和 5 条 X 帖子）。只保留去重后的结论。原始报告和证据链接在调研者手中，本文只记出处类别。

**证据等级**：
- **强**：三个来源中两个以上独立出现，且有原话或行为证据。
- **中**：单一来源，或者只有搜索索引、没读到正文。
- **弱**：转述、利益相关方的说法，或少于 3 条证据。

## 1. 目标用户

产品目的（产品决定，2026-11-10，见 [ADR 0009](adr/0009-survey-read-retain.md)）：让科研新手也能全面调研一个课题、快速读懂一篇文献、沉淀自己的长期知识库，适用于所有研究者。

| 人群 | 优先级 | 特点 |
|---|---|---|
| 研一、研零 | 首要 | 痛点最密集：读得慢、没人教、工具配不起来、怕组会；对配置最敏感 |
| 研二以上、博士 | 次要 | 关心创新点、和课题的关系、综述、可核验引用、期刊分区；读新方向的论文时同样卡在新概念上（产品决定，2026-11-08），概念释义对他们同样是核心功能 |
| 本科 | 暂不针对 | 三轮都没有足够样本（证据：弱） |
| 青年教师、CS 方向技术用户 | 可选 | 会用 Claude Code 等 agent，能接受配置（证据：弱） |
| 中文以外的研究者 | 不专门针对，但不设障碍 | 三轮调研都只覆盖中文用户，没有证据；界面语言和阅读语言做成配置项，提供中文和英文界面，中文先做（产品决定，2026-11-10） |

学科：理工和医学的证据最多，人文社科不足。

## 2. 核心痛点（去重后，按证据强度排序）

| # | 痛点 | 等级 | 要点 |
|---|---|---|---|
| P1 | 读完留不下 | 强 | 读完就忘，说不出创新点和与自己课题的关系；顺着引用越读越散，“一小时后什么都没消化” |
| P2 | 读得慢 | 强 | 术语和长难句是头号障碍；“翻译出来了还是不懂”，缺的是概念，不只是译文；新手读一篇要几周 |
| P3 | 没人教方法 | 强 | 检索、读法、组会汇报都靠上论坛问陌生人；不会提关键词，不会用学科自己的说法检索 |
| P4 | 不敢信 AI | 强 | 编造的文献和期刊信息已造成导师打回、撤稿；术语翻错伤害信任 |
| P5 | 笔记散、找不回 | 强 | 笔记分散在多个工具，和原文脱节，无法跨论文对比；失败在找不回来，不在存不下 |
| P6 | 工具配置和使用难 | 强 | Zotero 插件报错、配 API key、命令行都会劝退；日常还有卡顿、导入失败、引用样式难输出 |
| P7 | 下载不到 | 强（中文侧） | 外文没有权限；小木虫求助版有 1.8 万个主题，绕行已成常态 |
| P8 | 付费意愿弱且偏负面 | 强 | 正面证据为零；嫌贵、拒绝为云存储付费、付费后后悔；国产便宜模型可以接受 |
| P9 | 综述难、AI 率卡死 | 中 | 难在找研究空白、做批判性综合；学校查 AI 率，不敢让 AI 写正文 |
| P10 | 组会恐惧 | 中 | 导师要的是“你看出了什么”，不是逐页复述；怕被问倒 |
| P11 | 跟不上文献量 | 中 | 期刊目录看不完；也有人“求别再推荐新论文，先让我追上” |
| P12 | 期刊分区要求 | 中 | 毕业和考核看中科院分区、JCR、CCF，标准由导师或学校给定 |

调研中没有发现的（不作为需求依据）：
- 翻译后排版乱，只有 1 条利益相关的说法。
- 有人提到 BabelDOC 或双语 PDF：零提及。
- 引用格式本身的抱怨。
- “每周要读 N 篇”的具体数字。
- 正面的付费意愿。

## 3. 需求

优先级：**P0** 是第一个可用版本必须有的；**P1** 紧随其后；**P2** 在条件满足后再做。

### 3.1 领读

| 编号 | 需求 | 验收标准 | 依据 | 优先级 |
|---|---|---|---|---|
| R1 | 读前背景卡：这篇论文要解决什么，需要先懂哪些概念 | 每个概念有简短解释，并注明出处（原文页码或被引文献）；不懂的概念可以展开 | P2、P3 | P0 |
| R2 | 全文翻译与双语对照 | 整篇翻译是常规功能，不是例外：可以保留版式在原 PDF 上显示译文，也可以左右双栏对照；也能逐段、按页翻译；随时切回英文原文；公式、表格、引用编号保留原样 | P2；全文对照是刚需（产品决定，2026-11-08，推翻原先“原文优先”的假设） | P0 |
| R3 | 课题术语表 | 每个研究画像一张；用户可以改；翻译和解释必须按它来；术语悬停能看到释义 | P2、P4 | P0 |
| R4 | 边读边问 | 针对选中段落提问；回答引用原文页码；不提供依据的回答要标明 | P2、P4 | P0 |
| R5 | 前置阅读指引 | 列出读懂本文最需要先看的 3–5 篇引用，并说明原因，防止越追越深 | P1、P11 | P1 |

### 3.2 读后沉淀

| 编号 | 需求 | 验收标准 | 依据 | 优先级 |
|---|---|---|---|---|
| R6 | 组会视角的读后卡片 | 固定字段：问题、已有方法的不足、本文做法、关键证据、局限、创新点、和我课题的关系、导师可能会问的问题；每条都带原文页码；模型概括和作者原话分开显示 | P1、P10 | P0 |
| R7 | 笔记集中、可检索 | 所有卡片和用户批注存在同一处；一个搜索框查论文、笔记、回答卡片、问答和概念；每条能跳回原文位置 | P5 | P0 |
| R29 | 文库 | 读过、在读、待读的论文都能在一处找到，按课题和状态筛选；读完的论文不会从界面上消失 | P5；产品决定（2026-11-10，见 ADR 0009） | P0 |
| R31 | 数据带得走 | 论文条目、读后卡片、回答卡片、笔记、概念可以随时整体导出为 Markdown、BibTeX、CSL-JSON；不依赖拾穗也能打开 | P5、P8；产品决定（2026-11-10，见 ADR 0009） | P1 |
| R8 | 跨论文对比表 | 同一研究画像下，按方法、数据、指标、结论列表对比，能导出 | P5、P9 | P1 |
| R9 | 定期回顾 | 按间隔重复安排复习知识库里的概念，复习题从用户自己写过的回答出发；自评不产生模型费用 | P1；产品决定（2026-11-08，见 ADR 0007） | P1 |
| R26 | 个人知识库与个性化引导 | 每篇论文给 3 个引导问题（理解、对比、迁移），每题一张回答卡片，先写后看；系统评价回答并附原文依据，评出概念掌握程度，用户可以修改；知识库全局一份，课题作标签；下一篇的导读按掌握程度定制，已懂的少讲，不懂的用已知概念类比 | P1、P2、P10；产品决定（2026-11-08，见 ADR 0007） | P0 |
| R32 | 论文间记忆 | 读新论文时，导读和问答提起文库里与它相关的论文（扩展、用了谁的方法、实验比较、结论矛盾、思路相近），每条附双方原文和用户当时的笔记；不凭空声称关系；不额外配置也能看到引用和共享概念这类事实关系 | 用户问题（2026-11-11）；产品决定（见 ADR 0010） | P0 |

### 3.3 找文献

| 编号 | 需求 | 验收标准 | 依据 | 优先级 |
|---|---|---|---|---|
| R10 | 用中文研究描述生成英文检索式 | 用户用中文写背景、内容、目标；系统给出英文检索词和同义词，**逐个说明为什么选**（兼作教学），并预估能搜到多少篇；用户确认后才生效 | P3 | P0 |
| R11 | 推荐理由对照研究目标 | 每篇说明对应哪个目标、可以借鉴什么，附原文引用 | P1、P4 | P0 |
| R12 | 期刊分区筛选 | 用户导入导师或学校给的分区表（CSV，支持中科院、JCR、CCF）；卡片显示分区；可以按分区过滤；不内置受授权限制的分区数据 | P12 | P1 |
| R13 | 入门清单 | 并入 R27 的阅读路线 | P3 | — |
| R14 | 全文获取途径 | 每篇标明开放获取链接、需要校园网的出版商链接或找不到；上传自己拿到的 PDF 见 R28 | P7 | P1 |
| R27 | 课题调研 | 新课题启用时做一次有边界的调研：历史检索加引文扩展，执行前显示预计篇数和费用；给出阅读路线（综述、奠基论文、代表作、最新进展）和课题地图（子方向分组）；每轮报告新增多少篇，并写明检索了哪些来源、没有覆盖什么 | P3、P9、P11；产品决定（2026-11-10，见 ADR 0009） | P0 |
| R28 | 读自己手里的论文 | 贴 DOI、arXiv 编号、链接，或拖入 PDF 就能在领读器里打开；不要求先建研究画像；元数据仍然只来自学术数据源 | P7；用户测试要读测试者自己方向的论文（ROADMAP 第 6 步）；产品决定（2026-11-10，见 ADR 0009） | P0 |
| R15 | 推送量受控 | 默认低频（按周或按需），篇数可设；未读积压过多时自动减少推送 | P11 | P1 |

### 3.4 信任与引用

| 编号 | 需求 | 验收标准 | 依据 | 优先级 |
|---|---|---|---|---|
| R16 | 元数据从不经过模型 | 标题、期刊、作者、DOI 只来自学术数据源；界面上标明哪些内容由模型生成 | P4 | P0 |
| R17 | 可核验的引用导出 | 只导出有真实 DOI 或 arXiv 编号的论文；支持 BibTeX，以及国内常用的 GB/T 7714 | P4、P6 | P1 |
| R18 | 综述骨架，不代写正文 | 提供按目标或方法分组的提纲、对比表、研究空白候选（每条附证据）；不生成成段正文 | P9 | P1 |

### 3.5 上手与成本

| 编号 | 需求 | 验收标准 | 依据 | 优先级 |
|---|---|---|---|---|
| R19 | 零配置启动 | 不用命令行就能安装运行；不配置任何东西就能打开论文、高亮、做笔记；第一次用到模型时才在原地引导选模型提供方和填 key（推荐免费或低价模型）；本机 agent、飞书、Zotero 在设置页，不挡在上手路上；不装 Zotero 也能用全部核心功能；未配置飞书时可以在领读器首页看推荐；界面文案不出现命令行 | P6；ADR 0009 | P0 |
| R20 | 尽量不让用户额外付费 | 支持 DeepSeek 等国产低价 API、免费模型和 OpenAI 兼容的本地网关；边读边问可以复用用户本机已有的 agent（Codex、Claude Code、DeepSeek Harness 等）；显示每篇和每月的花费或额度；可以设上限 | P8；用户不愿为 API 付费（产品决定，2026-11-08，见 ADR 0005、0008） | P0 |
| R21 | 免费、本地 | 开源免费，数据存在本机，不依赖收费的云存储 | P8 | P0 |
| R22 | Zotero 可选同步 | 一键把论文、卡片、PDF 写进 Zotero；不需要安装任何 Zotero 插件 | P6 | P1 |
| R23 | 飞书卡片推送 | 推送渠道是飞书卡片，卡片可以跳转到领读器；配置有图文向导，尽量减少步骤 | 产品决定（ADR 0001） | P0 |
| R24 | 接入本机 agent | ① 作为模型通道：边读边问可以走用户本机的 agent，先支持 Codex、Claude Code、DeepSeek Harness；其他任务走 API（ADR 0008）；② 给外部 agent 提供只读查询接口 | 产品决定（2026-11-08，见 ADR 0005、0008） | ① P0，在 API 跑通之后，② P2 |
| R30 | 语言 | 界面语言和阅读语言（译文、讲解、卡片的语言）可以设置；提供简体中文和英文界面；论文语言与阅读语言相同时不翻译 | 产品决定（2026-11-10，见 ADR 0009）；非中文用户的需求没有证据 | 配置项和中文界面 P0，英文界面 P1 |
| R25 | 多平台 | 先做网页版（本机服务 + 浏览器）；学生大多用 Windows，Windows 必须一等支持；之后兼容 macOS、Linux，再考虑手机端 | 产品决定（2026-11-08） | 网页版和 Windows P0，其余 P2 |

## 4. 不做、不承诺

- 绕过授权下载：Sci-Hub、代下载、镜像站。
- 代写综述或论文正文。
- 内置中科院分区、JCR 等受授权限制的数据。
- 解决导师不教、组会焦虑、学校授权、AI 率检查：工具只能部分缓解，不在宣传中承诺。
- 订阅制收费，以及云端存储用户文献。

## 5. 待验证的假设

| 假设 | 现状 | 怎么验证 |
|---|---|---|
| ~~“原文优先、翻译按需”比全文对照更受欢迎~~ | 已由产品决定关闭（2026-11-08）：全文对照是刚需，见 R2 | — |
| 学生用不用飞书 | 证据不足 | 原型阶段问卷 |
| 每日推送是负担还是解药 | 两种说法都有，证据都弱 | 原型中比较不同推送频率下的打开率 |
| 本科、人文社科的需求 | 样本不足 | 下一轮定向调研 |
| 中文以外的研究者有同样的痛点 | 没有证据 | 英文界面发布后收集反馈 |
| 覆盖度指标能让新手判断“调研够了” | 没有证据 | 用户测试中观察：看到覆盖度后是否停止继续扩展，事后是否漏掉了导师认为必读的论文 |
| 不用命令行安装的可行路径 | 未调研 | 技术选型：打包桌面安装包，或一键脚本 |

## 6. 架构决策

第 6 节原列出的四处冲突已由 [ADR 0001](adr/0001-reader-push-distribution.md) 决定：

1. 自建领读器，Zotero 改为可选同步。
2. 推送仍用飞书卡片。
3. 发布形态是桌面安装包加常驻服务。
4. 以原文为主，按需翻译，支持双语对照，双语 PDF 作为可选导出。（已由 R2 和 ADR 0006 修订：全文翻译是常规功能。）

对应设计见 [ARCHITECTURE.md](ARCHITECTURE.md) 第 12 节和第 15.5 节。

[ADR 0009](adr/0009-survey-read-retain.md)（已接受）按产品目的调整：课题调研成为一等流程（R27），任何论文都能直接读（R28），领读器按调研、阅读、知识库组织页面（R7、R29、R31），语言成为配置项（R30），上手改为渐进式（R19）。对应设计见 ARCHITECTURE.md 第 7.5、12.8、15.5、15.6 节。
