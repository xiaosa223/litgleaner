# 论文间记忆：文库事实查询

论文页可调用本地只读接口，查看当前论文与其他文库论文之间已有的事实。接口沿用领读器会话、Host 和 Origin 检查。

```http
GET /api/papers/{paper_id}/memory-facts?limit=50&offset=0
```

文库范围沿用 `/api/library`：存在阅读状态、未删除批注，或用户添加流程已完成。`queued`、`reading`、`read`、`abandoned` 均在范围内；没有阅读状态的已添加论文显示 `new`。关系两端都须在文库内，流水线候选不作为邻居。未知或尚未入库的请求论文返回 404，查询不会替用户加入文库。

`limit` 为 1–200，默认 50；`offset` 为非负整数。结果按对方论文 ID 稳定排序，`total` 为分页前的完整邻居数，超出范围返回空 `matches`。参数越界返回 422。

## 返回的事实

顶层包含 `paper`、`matches`、`total`、`limit`、`offset` 和 `warnings`。每个 `matches` 条目包含对方论文的编号、标题、阅读状态及下列信号；无任何共同事实的论文不出现在列表中。

| 字段 | 含义与证据 |
|---|---|
| `cites` | 本篇引用对方的全部来源记录 |
| `cited_by` | 对方引用本篇的全部来源记录 |
| `common_references` | 双方共同引用的不同目标；`here`、`there` 保留各自全部来源证据 |
| `core_concepts` | 双方当前提取中的同一个核心概念；保留两侧 occurrence、页码、坐标和指纹 |
| `datasets`、`methods` | 已核验字段的名称精确匹配；保留两侧原文、零基页码、提取 ID、输入与生产者指纹 |

引用保留 `source`、`raw_text`、`contexts`、`intents`、`influential`、页码及坐标，原始来源之间不互相覆盖。已保存的目标论文 ID 沿用既有事实；未保存 ID 时，使用**全库**别名唯一精确匹配，库外的别名冲突同样阻止误关联。

共同参考目标可以尚未入库。共同出现的明确别名用于归并同一目标；没有标识符的条目不按标题猜测。跨条目别名链最终指向多篇论文时，不参与共同目标计算。多来源引用同一目标仍计为一个共同目标，原始证据全部保留。这里返回原始共同目标，文献耦合阈值和重要前作判断随候选策略实现。

数据集与方法目前使用提取的 `text`，只统一 Unicode、大小写和空白；不把概括文字拆成类别或猜测缩写。核心概念沿已有概念编号和已登记别名识别，并要求当前提取仍把对应名称与位置标为 `core`。定义未核验时保留 `verified=false` 和空定义，不补造定义。

## 指纹与诊断

每篇只使用最大 ID 的提取。提取输入必须匹配当前文档指针、切分规则、阅读语言、发送预算和提取协议；已配置提取模型时，生产者还须匹配当前提示词、请求模型与提供方。不会回退旧提取以补足事实。

`warnings` 覆盖整个参与查询的文库，按论文 ID 和检查顺序稳定返回。它与 `matches` 分开，空结果也能说明缺失原因。

| code | 处理 |
|---|---|
| `missing_extraction` | 没有提取，只参与引文关系 |
| `missing_document` | 没有当前文档指针，跳过提取信号 |
| `stale_input`、`stale_producer` | 已知输入或生产者失配，跳过提取信号 |
| `producer_unchecked` | 未配置提取模型；保留输入可核对的已有事实，注明生产者未完整核验 |
| `legacy_fields` | 旧提取缺字段或字段容器错误，缺失部分不参与匹配 |
| `stale_concept` | 旧 occurrence 与最新提取指纹或当前核心名称、角色、位置不符，跳过该概念 |

只接受持久化时已标 `verified=true` 且结构完整的数据集和方法证据，读取不重新解析全文或重做引文核验。原文片段和坐标用于回到出处；解析文本自身仍可能包含识别错误。

## 执行与后续范围

一次请求在短事务内以固定 **8 次 SELECT** 读取完整文库、一致的最新提取与原始引文，以及全库别名。概念别名通过同一次连接查询读取。事务结束后计算投影，不逐论文补查。接口不写数据库、队列或归档，不调用模型、来源服务或下载本地向量模型。

本接口是 [ADR 0010](adr/0010-paper-memory.md) 的事实查询部分。[本地向量](LOCAL-EMBEDDINGS.md) 已有显式重算、相似度只读接口及历史过期核验；事实、向量与已有 FTS 的[候选加权与阈值](MEMORY-CANDIDATES.md) 已有只读接口。[首次入库、`relate` 核实与用户关系反馈](PAPER-RELATIONS.md) 已接线。重要前作、`paper_mention` 及阅读页/问答记忆上下文仍按该 ADR 后续实现。
