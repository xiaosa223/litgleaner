# 本地论文向量

本地向量为文库论文提供余弦相似度信号，用于候选排序和问答混合召回。相似度本身不产生“扩展、矛盾、方法相同”等语义关系；这些关系由 [ADR 0010](adr/0010-paper-memory.md) 的 `relate` 流程核实。

## 安装和显式重算

可选组件通过项目依赖安装：

```bash
uv sync --extra memory
uv run litgleaner memory reembed
uv run litgleaner memory reembed --execute
uv run litgleaner stale --kind embedding --format json
```

默认命令只预览模型、本地就绪状态、文库总数、精确缓存数、待算论文 ID、跳过项和诊断。只有 `--execute` 会加载本地推理引擎、首次准备模型文件并保存向量；首次执行可能下载模型。计算不调用收费模型或学术来源。

执行共用流水线的运行锁；锁被其他任务占用时返回退出码 3。每批先完成推理与全部数值校验，再在短事务中重查文库范围、实际输入和当前模型身份；期间变化的论文列入 `changed_paper_ids`，不保存该次结果。已保存批次保留，重试复用精确缓存。历史联合指纹已存在时不覆盖。

## 配置

可选 `config/memory.yaml` 缺失时使用相同默认值：

```yaml
embedding:
  enabled: true
  adapter: fastembed
  model: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
  dimensions: 384
  threads: 1
  batch_size: 16
  max_input_chars: 8000
  # cache_dir: data/models/embeddings
```

默认缓存放在数据库所在目录的 `models/embeddings` 下，再按模型和推理配置隔离；自定义相对路径以项目根目录为准。设 `enabled: false` 关闭本地向量。缺少可选依赖、尚未准备资产或缓存不完整时，启动及其他功能照常运行，向量信号暂缺。

模型和维度必须与安装版本支持的模型清单一致，在显式执行时校验。推理固定使用 CPU。模型选项、资产内容和推理运行库版本都进入生产者指纹；更换模型后旧向量仍保留，由 `stale` 列出。

## 输入与资产核验

输入按 `title`、`abstract`、`problem`、`approach` 的顺序加标签，只包含非空文本。先统一 Unicode 和空白，再取 `max_input_chars` 个字符的连续前缀；实际文本与输入协议版本共同决定 `input_hash`。相同实际文本可复用缓存；未使用的提取字段变化不会导致重算。

提取只采用当前最大 ID，须对应当前文档、切分、阅读语言、预算及已配置的生产者。缺少或过期提取时，只用标题摘要。未配置提取模型时仍可使用输入可核对的已有提取，并注明生产者未完整核验。这些提取概括用于候选信号，不宣称已核实语义关系。`source_extraction_id` 仅在实际前缀包含至少一个提取正文字符时保存；只有字段标签落入前缀时不声明该出处。

首次成功推理后，适配器原子保存模型资产清单，包括文件内容 SHA256、大小和状态。此后显式计算前后都核对内容，内容变化时拒绝沿用旧资产身份；单纯移动缓存目录或刷新文件时间不改变内容身份。分批计算复用同一生产者的推理实例，每批仍核对资产内容；进程内更换运行库后须重启，避免给已加载的旧代码记录新版本。

启动、默认预览、相似度接口及 `stale` 只查看本地清单、文件状态和依赖元数据，不导入嵌入 SDK、不构造推理实例、不联网、不生成向量。清单或模型目录损坏、路径越界及软链接环会使向量模型暂不可用，并给出诊断。

迁移 0018 新增只追加的 `paper_embedding`。向量按小端 float32 保存，写入和读取时校验维度、有限值和非零范数。若当前联合指纹已有损坏记录，读取会跳过并诊断，重算会停止并提示检查或还原数据库，避免覆盖历史。

## 只读相似度接口

```http
GET /api/papers/{paper_id}/memory-similar?limit=5
```

接口沿用本地会话、Host 和 Origin 校验；`limit` 为 1–200，默认 5。请求论文和候选都限文库，未知或未入库的论文返回 404。只比较当前实际输入、生产者及维度一致的有效向量，排除自己，按余弦降序、论文 ID 升序排列。返回 `paper_id`、模型状态、`matches`、分页前总数 `total` 及诊断；每条匹配带对方 ID、标题和 `cosine`。

模型未就绪或请求论文尚无当前向量时，返回空匹配及原因。数据读取固定 4 次 SELECT 窄快照，不受文库默认分页上限影响；不为查询准备模型或重算向量。文库事实接口仍保持其独立的 8 次 SELECT 合同，见 [PAPER-MEMORY](PAPER-MEMORY.md)。

`stale` 的 `embedding` 类型核验全部历史。模型文件缺失或可选依赖不可用时，对无法完整核验的生产者标 `unknown`；已知文本或配置失配仍为 `stale`。实际输入使用了生产者未完整核验的提取时，也会列出 `unchecked`。`selected` 表示当前候选查询实际是否选用，与完整核验状态分开。

## 问答中的临时向量

提交新问题时，[问答上下文](QA.md#有界混合召回)可使用已就绪资产计算问句与选区的临时向量，和当前有效的论文向量缓存比较，召回最多五篇正相似度论文；随后可对最多 64 个原文候选计算临时向量，与词法和有效 FTS 分数合并重排。用户笔记和历史问题沿规范用户来源召回，模型摘要只作背景；向量相近不能直接成为回答证据。

这条路径禁止下载，也不重嵌入或写入论文向量。推理前后核对模型身份及输出数值；资产缺失、配置关闭、身份竞态或推理失败时说明降级，其余词法、FTS 和有效关系信号继续工作。来源片段和完整消息在排队时冻结，之后的执行及 `stale` 核验不重新做向量召回，不因新增未选论文或记忆而扩张旧问题。

当前验收使用离线 SDK 替身、临时数据库和真实 CLI/API 入口；真实模型下载、推理效果及 Windows 真机待实测，进度见 [ROADMAP.md](ROADMAP.md)。事实、向量和已有 FTS 的只读候选加权见 [MEMORY-CANDIDATES.md](MEMORY-CANDIDATES.md)。[首次进入文库的自动计算与 `relate` 接线](PAPER-RELATIONS.md) 已实现，自动模式同样仅使用已就绪资产。全局搜索的向量混合排序仍待接线。
