# 个人数据导出后端

个人导出读取 SQLite 中的全部论文和概念，生成 Markdown、BibTeX 与 CSL-JSON。默认不包含 PDF；明确选择时只复制本地已有的原 PDF。导出不调用模型、不请求来源、不排队、不改变阅读状态或历史记录，缺模型配置和每日额度为零时也可使用。

## 命令行和接口

```bash
uv run litgleaner export mine --out ./my-export
uv run litgleaner export mine --out ./my-export-with-pdfs --include-pdfs
```

`--out` 必须是新目录。已有文件、目录和符号链接均拒绝，包含并发出现的同名目录。目录独占创建后写入文件；普通失败清理本次创建的文件和空目录，保留其他并发出现的内容。`manifest.json` 最后写入；进程被强制终止后如果没有清单，该目录属于未完成导出，不能当作完整结果。

`POST /api/exports/mine` 提供同一套内容的 ZIP 下载，请求体可省略、为 `{}`，或为 `{"include_pdfs":true}`。该布尔字段拒绝字符串和整数；其他字段也被拒绝，网页不能指定服务器输出路径。接口需要本机会话与 `X-CSRF-Token`，复用 Host、Origin 和请求体大小保护。

下载响应是 `application/zip`，文件名为 `litgleaner-export.zip`，设置附件下载与不缓存。ZIP 超过内存暂存阈值后使用系统临时文件；正常完成和失败时释放资源。下载包不会存入业务数据库或作为历史导出留在数据目录。

## 导出内容

| 文件 | 内容 |
|---|---|
| `README.md` | 导出范围、页码和来源说明，论文与概念索引 |
| `papers/<稳定哈希>.md` | 每篇论文的元数据、全部标识符、全部提取与评估历史、规则评分、有效笔记和高亮、阅读进度及完整问答 |
| `concepts/<稳定哈希>.md` | 每个概念、别名及全部出现位置，含核验状态、原文定义、页码和版本 |
| `references.bib`、`references.csl.json` | 有有效 DOI 或文献编号的论文引用；只使用来源元数据 |
| `NEEDS-VERIFICATION.md` | 缺失、无效或歧义标识符的论文，以及引用警告；这些论文的 Markdown 仍会导出 |
| `pdfs/<稳定哈希>.pdf`、`PDFS.md` | 仅在明确包含 PDF 时生成；索引只链接实际成功导出的 PDF |
| `manifest.json` | 快照时间、范围、缺项、警告，以及其余文件的字节数和 SHA-256 |

这里的“全部论文”包括尚未阅读或未进入个人文库视图的论文，不套首页推荐窗口、课题初筛或文库筛选。问答也不使用通常的最近 50 条限制。已软删除的批注不会导出；提取、评估和各评分规则的历史版本全部保留，不把旧判断冒充当前结果。

文件名由完整内部编号的 SHA-256 生成，标题、概念名和外部编号不进入文件路径。内容中的 HTML、Markdown 标记及反引号通过转义或自适应代码围栏作为文字保存。ZIP 和目录写入共同拒绝路径穿越、不可移植名称、重复文件及文件/目录冲突。

## 来源、引用和 PDF

作者摘要按来源原文保留。笔记正文和问题标为用户所写，选中文本标为“用户选中文本，未单独核验”；提取摘要、结论、局限概括、评估理由和问答正文分别标为模型生成，问答中的模型推断保留标记。有已保存核验状态的引文和概念定义标为作者原文；未核验的模型引文保留待核验说明。规则计算的评分与模型判断分开。

正文中的“PDF 第 N 页”从 1 开始；原始 JSON 中的页码保持数据库零基编号。缺少页码时明确写“页码未记录”，不会根据引文猜页。模型、提示词、输入指纹及时间按原记录保留；来源没有保存的字段不会补造。

引用中的作者使用原始字面姓名，不猜姓与名。只有明确保存的来源文献类型才映射成书籍、章节、期刊或会议等类型；未知或冲突的类型使用通用类型，冲突附警告。不根据标题或刊名猜类型，也不生成卷、期、页码或出版社。标识符按现有规范化规则校验；多个不同的同类有效标识符不任意挑选。BibTeX 特殊字符被编码，CSL-JSON 保留原始字面字符串。

PDF 从快照中的哈希定位，只读本地 blob。复制前验证哈希格式、实际内容 SHA-256 和 PDF 文件头；不重新下载、不解析、不生成译文 PDF。缺少 PDF、无法读取或校验失败均在清单中逐篇报告，其他文件仍正常导出。

## 当前边界与验收

当前版本没有用户回答卡片、评价和掌握程度的源表。导出明确注明回答卡片尚未提供，模型问答不会代替用户回答卡片；这些独立模块落库后还需扩展导出快照和投影。读后卡片目前来自提取结果，导出保留全部版本。

数据库读取在短事务中完成，固定 12 次批量查询，不随论文数增加查询次数，不使用大量 ID 绑定参数；格式渲染、PDF 读取与文件写入都在事务外进行。不新增业务表或迁移。离线验收覆盖空库、未读论文、1000 篇规模、61 条问答、各版本与评分历史、并发快照、来源与页码、引用元数据、PDF 缺失和损坏、目录并发、安全拒绝及 CLI/API 内容一致。设置页尚未接入下载操作。

完整 2597 项测试通过，覆盖率 94.92%；Ruff、387 文件格式检查、Mypy 253 个源文件及 3 项依赖契约通过。独立审查发现的文献类型映射和下载异常资源释放问题均已修复并通过回归，包含 ASGI 2.3/2.4 发送异常与取消。未使用真实来源、付费模型或文献管理软件联调。
