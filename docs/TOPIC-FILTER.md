# 初筛前的本地关键词过滤

`TriageStage` 先用 `domain.keyword_filter.filter_keywords` 检查论文标题和摘要，通过后才调用初筛模型。期刊监控返回的无关论文也走这条规则。

- 包含词使用 `query.include`，并展开每个包含词在 `query.synonyms` 中的同义词；任一命中即可通过。
- `query.exclude` 优先：即使包含词命中，出现排除词仍拒绝。
- 匹配先做 NFKC、大小写和空白归一化。ASCII 词和短语使用边界，`GAN` 不匹配 `organ`；中文按连续子串匹配。
- 包含词（`keyword-filter-v2`）：多词英文检索词在标题或摘要的**同一字段**里出现全部实词即可，顺序不限、忽略停用词；5 个字母以上的词去掉常见后缀后按词干前缀匹配（`faithfulness` 命中 `faithful`，`explainability` 命中 `explainable`），5 个字母以内的词只允许复数变化；单个短缩写、中文和含符号的词（`C++`）仍精确匹配。排除词仍按完整短语精确匹配。v1 要求整个短语原样出现，2026-11-14 用真实 OpenAlex 调研实测，70 篇候选里有 56 篇被拦下，其中不少明显相关（见 [实测](experiments/2026-11-14-guidance-real-model.md)），不符合第 7.4 节“只拦完全不相关的”。
- 没有配置包含词时，只按排除词过滤；缺摘要时仍检查标题。

拒绝结果仍写入当前课题指纹下的 `triage`，`model="rule"`、`prompt_version` 为当前规则版本（`keyword-filter-v2`），保留拒绝原因且不调用模型。后续初筛、全文获取和评估沿用现有预算。

排队任务固定 `topic_hash`。课题定义变更、课题暂停或已有当前指纹下的初筛结果时，执行前跳过。暂停期间跳过且尚无结果的任务，可在重新启用后或显式回填时继续；不会因重新启用重复筛查已完成论文。旧任务没有指纹时，只接受数据库中当前课题指纹对应的旧队列记录。

规则只判定关键词相关性，不替代研究画像模型初筛。调整检索式后，历史论文仍需显式 `topic backfill ... --execute`；规则变更不会自动调用模型重筛历史。
