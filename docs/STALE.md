# 派生结果过期报告

`litgleaner stale` 比较已保存的派生结果与当前配置、原文和课题范围，帮助决定历史结果是否需要重做。命令只读本地数据库、文档归档和模型缓存状态，不调用模型或来源、不修改记录、不排队任务。

```bash
uv run litgleaner stale
uv run litgleaner stale --include-current
uv run litgleaner stale --kind extraction,score
uv run litgleaner stale --format json
uv run litgleaner stale --config /path/to/config --kind outline --format json
```

默认文本输出先给汇总，再逐行输出过期或未完整核验的记录；`--include-current` 同时显示核验通过的记录。`--kind` 可用逗号限定类型。JSON 始终包含所选类型的全部状态，便于脚本读取。命令成功返回退出码 0，状态通过输出中的 `status` 判断。

## 状态和字段

| 字段或状态 | 含义 |
|---|---|
| `current` | 当前可核对的输入和生产者指纹完整，且全部匹配 |
| `stale` | 至少一项已知指纹失配，原因见 `reasons` |
| `unknown` | 尚无已知失配，但缺少完整核验所需的信息，说明见 `unchecked` |
| `selected` | 当前读取路径是否选择这条历史记录；无法定位适用范围时可为 `null` |
| `paper_id` / `topic_id` | 原记录关联的论文和课题；全局或不适用的关联为 `null` |

已知失配优先：一条记录可以同时有 `reasons` 和 `unchecked`，此时状态为 `stale`。历史版本即使未被选中，也会独立核验，可能仍为 `current`；当前被选中的旧结果也可能为 `stale` 或 `unknown`。

JSON 的顶层字段为 `total`、`current`、`stale`、`unknown` 和 `items`。每个 item 带 `kind`、`id`、两个关联 ID、`status`、两个说明列表及 `selected`。顺序按类型、课题、论文、记录 ID 稳定排列。所有历史均参与核验，不受页面最近条数或历史分页上限影响。

## 核验范围

| `kind` | 核验内容 |
|---|---|
| `extraction` | 文档位置、切分、阅读语言、预算、提取合同，以及模型、提示词和提供方指纹；选中记录沿当前最大提取 ID |
| `assessment` | 研究画像、维度语义、评估输入和提示词；选中记录沿当前画像及维度下的最新评估 |
| `score` | 评估核验结果及权重、门槛、等级线策略；最新评估没有当前策略的分数时不回退旧评估 |
| `translation` | 段落原文、翻译单位、目标语言、句数、术语表和译者版本；精确缓存优先，其次沿阅读页规则选择旧译文 |
| `answer` | 问题语言、已保存的任务文档和切分指纹、提示词，以及当前实际发送的选区、画像和正文上下文 |
| `map` | 课题画像、已发送的论文来源、语言、预算和生产者版本 |
| `outline` | 课题画像、已发送的已读论文及其冻结来源、语言、预算和生产者版本 |
| `embedding` | 实际嵌入文本与预处理协议、模型与推理配置、运行库及模型资产身份、float32 数值和维度；全部历史保留，选中状态沿当前文库及相似度读取路径 |

旧评估和问答记录没有保存请求模型与提供方的完整指纹，因此即使其他核验均通过，仍为 `unknown`。响应中的模型名可能与请求别名不同，报告不会用两者字符串差异判断换模型。缺少当前任务模型时，仍可核对已知输入变化，其余部分记入 `unchecked`。

译文缓存是全局缓存。报告保留原始 `paper_id`，并按当前任何论文中实际相同的段落核对适用性；无法定位原文时保留为 `unknown`。尚未生成的结果不产生报告项，例如只有问题但还没有答案时不会生成一条过期答案。

地图和综述只核对各次生成时已经发送的论文。新增论文由对应功能提示待整理数量，不会直接使原结果过期。较旧历史只要仍匹配当前配置和来源，可以优先于较新的失效版本。综述的来源论文退出已读范围后，对应历史会过期。

## 只读保证与后续处理

一次短事务固定读取 15 组数据库结果，事务结束后才解析历史并核验文档；核验阶段不再逐记录查库。同一个文档归档每次报告至多读取一次，读取失败也会缓存。缺失、压缩损坏或结构损坏的文档只影响相关结果，报告保留其他论文的核验结果。

嵌入模型缺少本地资产或可选依赖时，不把历史输入伪报为过期，未能完整核对的生产者列入 `unchecked`。实际使用了生产者未完整核验的提取时也注明；仍被当前候选读取路径选中的精确向量可同时为 `unknown` 和 `selected=true`，见 [本地向量说明](LOCAL-EMBEDDINGS.md)。

修改配置后，先用本命令查看影响范围，再显式选择后续操作：

- 权重或等级线变化：`litgleaner rubric rescore` 使用现有维度等级零模型费用重算。
- 研究画像或维度变化：使用 `topic backfill` 或 `rubric reassess` 先预览，确认范围后再执行。
- 翻译、地图和综述：使用各功能的显式重译或生成入口；已有历史继续保留。
- 提取：统一历史重提取入口仍待实现，见 [ROADMAP.md](ROADMAP.md)。
- 本地向量：`litgleaner memory reembed` 预览，`--execute` 显式计算；首次执行可能下载模型。

本报告不修改已有归档中的标记，也不替缺失的历史信息补造指纹。
