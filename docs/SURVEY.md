# 课题调研后端

调研使用已配置的研究画像和来源，先保存预览，再确认执行。默认执行两轮：第一轮检索历史综述、高被引论文、近两个日历年的论文，并扩展画像里的种子；第二轮从首轮有当前有效评分的高分论文扩展。后续扩展不重复历史查询。配置里的轮数就是本次确认的执行范围，结束后只给建议，不自动增加轮数。

## 命令行

```bash
uv run litgleaner topic survey example-topic
uv run litgleaner topic survey example-topic --execute --plan <预览编号>
uv run litgleaner run --stage survey
```

`--execute` 不带 `--plan` 时确认本课题最近一次用户预览；自动生成的后续轮次计划不会占用这个位置。重复确认同一计划返回原任务。常驻服务会自动处理已确认的按需任务；单独运行 `--stage survey` 可以只推进调研。

预览会请求来源并归档原始响应，不调用模型，不写入论文，不推进日常来源游标。确认复用保存的候选，不重新查询首轮来源。课题暂停时仍可预览和读历史，恢复启用后才能确认。

## 接口

所有接口需要本机会话，POST 还需要 `X-CSRF-Token`。预览请求体可省略或为 `{}`；确认只接受 `plan_id`，拒绝额外字段。

| 方法与路径 | 用途 |
|---|---|
| `POST /api/topics/{topic_id}/survey/preview` | 获取来源结果并保存预览 |
| `GET /api/topics/{topic_id}/survey/plans/{plan_id}` | 读取保存的预览 |
| `POST /api/topics/{topic_id}/survey`，`{"plan_id":"..."}` | 幂等确认并排队 |
| `GET /api/topics/{topic_id}/survey/runs/{run_id}` | 任务状态及各轮结果 |
| `GET /api/topics/{topic_id}/survey/rounds?limit=100` | 最近若干轮事实，按轮号正序返回；上限 1000 |

预览包含候选、来源回执、原始响应位置、未覆盖范围、本地拒绝数、已知论文数，以及首轮的 `triage_calls`、`fulltext_candidates`、`extract_calls` 和 `assess_calls`。全文候选数表示预计进入全文路径的论文总数，含已解析且可复用的论文。后续步骤数量按待初筛论文全部通过、未知全文能够取得的条件估算；已保存的负初筛、提取和评估会复用。

`estimated_usd` 是本次所有已确认轮次的初筛费用估算；`estimated_pipeline_usd` 加上提取和评估估算。首轮使用当前可复用结果计算调用数，尚未发现的后续轮次按候选上限计算。单次价格使用该任务实际历史费用均值，没有历史时为 `null`，零次调用为零。估算不是费用硬上限；实际开销以同轮 scope 的费用账本为准，包含已报告用量的失败响应，所有任务共享每日预算。

## 边界与恢复

`config/app.yaml` 的 `survey` 配置控制轮数、每轮候选数、每类历史检索数、每个种子的引文扩展数、种子数、起始日期和覆盖度阈值。历史被引扩展使用独立的 `HistoricalCitations` 协议，显式指定日期范围；日常 `CitationWatch` 的查询和游标保持原有语义。

每个来源单独返回数量、错误类型、警告和截断状态。历史查询与历史被引请求受查询限额及适配器 `max_records` 双重限制。`ReferenceList` 目前没有独立查询限额：网络读取受适配器 `max_records` 限制，返回后再按 `expansion_limit` 截断原始引文与对应候选，并报告未覆盖部分。最终候选优先保留被多个不同种子共同引用的论文，再按稳定身份键排序截断。

确认时重新检查当前配置指纹。研究画像、种子、来源配置、模型和提示词、阅读语言、评分规则、解析器、切分或正文预算变化后，旧预览需要重做。执行期间变化会取消剩余工作，保存已发生费用和取消事实；新增配置不会被旧任务用于继续收费。

确认后的工作集与每轮结果保留首次写入。已有标识符冲突的候选不猜测归属；是否新增按实际入库时的状态判定。调研进行期间，日常规划及旧排队任务避让其论文，防止绕过退避或丢失调研费用归属。取消、未完成或有失败的工作保留占用，显式重新预览并成功完成的后续轮次可以解除对应论文的失败占用。

模型预算耗尽时保持 pending；课题暂停或前置任务等待不会增加失败次数。普通子任务继续使用原重试、退避与死信规则。已结束轮次的子任务不接受通用 `jobs retry` 复活，恢复缺失结果需要重新预览调研；轮次费用和覆盖度不会被重试改写。

每轮保存来源贡献、失败任务、费用及：

```text
覆盖度 = 本轮以前没见过且通过初筛的论文数 / 本轮候选总数
```

候选为空、初筛未确定或已取消时，覆盖度及继续建议为 `null`。初筛未确定不作为“不相关”处理。低于配置阈值时建议停止扩展，否则建议研究者决定是否再调研。该值只描述已启用来源和查询范围内的新增产出；来源缺失、失败、限额之外的结果和检索式外的语言仍属于未覆盖范围。

迁移 `0015` 新增预览、工作集、只追加轮次及费用 scope，不重建旧论文表或全文索引。[课题地图](TOPIC-MAP.md)和[个人数据导出](PERSONAL-EXPORT.md)后端已实现，课题页仍为界面预览；画像起草继续按独立模块推进。来源、模型、网页 API 和 CLI 已通过离线适配器与真实本地队列验收，尚未调用真实来源或付费模型。
