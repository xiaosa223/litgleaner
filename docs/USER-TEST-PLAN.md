# 新手试用方案（路线图 D 步）

目的：检验拾穗能不能让研一、研二的同学**更快读懂一篇自己方向的论文**，并把弄懂的东西留在自己的知识库里；同时找出卡住、看不懂、不信任的地方。通过标准沿用 [ROADMAP](ROADMAP.md) D 步：

| 指标 | 门槛 |
|---|---|
| 完成时间 | 比参与者平时的读法短 |
| 理解小测正确率 | 不低于平时的读法 |
| SUS 可用性得分 | ≥ 70 |
| 信任问题 | 每篇不超过 1 次，且参与者能自己识别出来（例如点了“评价有误？”或指出“这句原文里没有”） |

不达标就回到 B、C 步修改，不进入发布。

## 参与者与分组

- 5–10 名研一、研二，各自带一篇**自己方向、还没读过**的论文 PDF（英文或中文均可，10–20 页为宜）。
- 交叉设计，抵消论文难度差异：每人读两篇难度相近的论文，一篇用拾穗，一篇用自己平时的方式（PDF 阅读器加通用聊天模型都可以）。一半人先用拾穗，一半人后用。
- 主持人事先为每篇论文写好理解小测（见下）。

## 测试前准备（主持人）

1. 用一份独立配置启动，不碰自己的数据：复制 `config/` 到新目录，`app.yaml` 里把数据路径改到新目录，`parser.adapter` 改成 `pdf_text`（默认演示解析器读不了真实 PDF），`jobs.backoff_seconds` 可调小到 30。
2. 在设置页“模型”里配置一个模型，勾选全部功能；在设置里给每日预算设一个上限（建议 $1）。
3. `uv run litgleaner serve`，用输出的链接打开；确认首页能看到“读一篇论文”。
4. 每位参与者用一个全新的数据目录（知识库从空开始），测完后在设置“数据”里导出 zip 留档。

## 任务脚本（读给参与者，约 45 分钟）

> 请像平时一样读这篇论文，目标是读完能跟导师讲清楚它做了什么、怎么做的、能不能用到你的课题上。觉得读懂了就告诉我。过程中请尽量把想法说出来。

用拾穗那一篇按下面顺序，主持人只在参与者卡住超过 2 分钟时提示：

1. 点“添加论文”，上传 PDF，等解析和提炼完成（约 1–3 分钟，期间可以先看原文）。
2. 在“导读”里把已经懂的概念点掉，生成导读，带着三个问题读。
3. 读的过程中可以选中文字翻译、提问、记笔记。
4. 读完在“读后”回答三个引导问题，看评价；觉得评价不对就点“评价有误？”。
5. 打开“知识库”，看看自己弄懂的概念和写过的回答。

## 记录（主持人填）

| 时间点 | 记录内容 |
|---|---|
| 开始、自认为读懂 | 时间（分钟） |
| 每次卡住 | 在哪一步、卡了多久、参与者说了什么、主持人有没有提示 |
| 每次“不信” | 参与者对哪句讲解、评价或引文表示怀疑；怀疑是否成立（核对原文） |
| 每次“惊喜”或“有用” | 原话 |
| 结束后 | 后台数据：生成导读次数、回答次数、评价次数、“评价有误”次数、本次模型花费（设置页“模型花费”） |

## 理解小测（两种读法各一份，读完立即做，不能看论文）

主持人按论文写 5 题，每题 0–2 分：

1. 这篇要解决什么问题？（1 句）
2. 核心方法是怎么做的？为什么有效？（2–3 句）
3. 主要结论和适用条件？
4. 和你知道的某个方法相比，异同在哪里？
5. 能不能用到你的课题上？怎么用、要先验证什么？

评分标准在测试前写好，两人独立评分，取平均。

## SUS 可用性量表（读完拾穗那篇后填，1 = 非常不同意，5 = 非常同意）

1. 我愿意经常使用这个工具。
2. 我觉得这个工具没必要这么复杂。
3. 我觉得这个工具容易使用。
4. 我需要有人指导才能用好这个工具。
5. 我觉得这个工具的各项功能结合得很好。
6. 我觉得这个工具前后不一致的地方太多。
7. 我想大多数人都能很快学会用这个工具。
8. 我觉得这个工具用起来很别扭。
9. 我用这个工具时很有信心。
10. 我要先学很多东西才能开始用这个工具。

得分 = （奇数题得分 − 1 之和 + 5 − 偶数题得分之和）× 2.5，满分 100。

## 结束后简短访谈（5 分钟）

- 导读讲的深浅合适吗？哪里讲多了、哪里没讲到？
- 三个问题和评价对你理解有帮助吗？有没有让你觉得被“考试”？
- 你会不会再用知识库和复习？为什么？
- 和你平时的读法比，最想保留和最想去掉的各一样。

## 结果整理

写到 `docs/experiments/<日期>-user-test.md`：每人一行（两种读法的时间、小测分、SUS、信任问题次数），再汇总是否达到上面四条门槛；问题按“卡住次数 × 影响”排序，标注对应的界面位置，作为下一轮修改的输入。不记录参与者姓名，论文和导出的数据经参与者同意后才保留。
